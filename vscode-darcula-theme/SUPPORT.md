# Support

When reporting a color issue, include:

- VS Code version and operating system
- Language mode and relevant language extension
- Whether semantic highlighting is enabled
- A minimal code sample or screenshot
- Expected color and actual color

For Kotlin issues, also include whether
`pyDarcula.kotlinDecorations.enabled` is enabled and whether the issue happens
in a call, declaration, string, or comment.

The extension has no telemetry or network requests. Until a public source
repository is attached, use the extension's Marketplace Q&A page for support.
